## Engineering focus

- **Backend systems:** modular NestJS services, REST APIs, validation, and clear separation of responsibilities.
- **Reliable processing:** background queues, retries, idempotency, and quarantining invalid data.
- **Data integration:** deterministic transformation pipelines and MongoDB persistence.
- **Flutter experiences:** cross-platform interfaces, animation, and custom 3D scenes.
